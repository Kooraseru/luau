# Switch dispatch experiment

This directory benchmarks the experimental `switch` syntax against an equivalent
linear `if/elseif` chain.

The parser currently lowers switches with distinct numeric literal cases into a
balanced binary dispatch tree. Non-numeric or duplicate numeric cases retain
source-ordered equality dispatch.

Generate benchmark programs with:

```bash
python benchmarks/switch/generate.py
```

Then build both CLIs and inspect bytecode:

```bash
cmake --build build --target Luau.Repl.CLI Luau.Compile.CLI
./build/luau-compile.exe --binary benchmarks/switch/generated/switch-256.luau
```

Runtime benchmark files print elapsed seconds and a checksum. Compare matching
case counts under the same Luau optimization level, e.g. `-O0`, `-O1`, and
`-O2`. The generated workload cycles through all case values in a deterministic
permutation so early and late linear cases are both exercised.

This is an experiment, not yet a claim that switch is universally faster. The
useful evidence is the crossover by case count, generated bytecode/control-flow
shape, and repeated runtime measurements.
